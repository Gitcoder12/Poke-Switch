# Contributing to Poke-Switch

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Verify official catalogue claims against official public sources.
3. Label independent fan games as unofficial and link to their legitimate project pages.
4. Do not upload or link to copyrighted ROM downloads or unauthorised assets.
5. Add tests for vote/request validation and duplicate handling.
6. Keep moderation and abuse reporting visible.
7. Open a PR with link-check and test results.

Human maintainers review moderation, public catalogue changes and releases.
