# Poke-Switch — Feature Upgrade Plan

## Objective

A community website where players can browse official Pokémon games and suggest or vote for game releases and features they would like to see.

## P0 — trust, legality and moderation

- [ ] Make official vs fan-made catalogues visibly distinct and verify each outbound link.
- [ ] Add report/moderation workflow, rate limits and anti-spam controls for requests/votes.

## P1 — catalogue experience

- [ ] Add searchable filters by platform, release year, region and official availability using sourced metadata.
- [ ] Add transparent vote totals and duplicate-request merging.

## P2 — community quality

- [ ] Evaluate community moderation load and ranking fairness.
- [ ] Add accessibility, mobile testing and data export/deletion controls.

## Contributor work packages

1. Official/fan-made metadata and link verification.
2. Request/vote model and duplicate merging.
3. Moderation, rate limiting and abuse reports.
4. Accessibility and user-data controls.

## Definition of done

- [ ] Every catalogue entry has a source and status.
- [ ] Fan projects are labelled independent and unofficial.
- [ ] User-generated content can be reported and moderated.
- [ ] No copyrighted ROMs/assets are hosted.
